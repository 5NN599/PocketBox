# Getting Help

- For a reproducible bug, open a Bug Report issue and include the PocketBox version,
  Windows version, steps to reproduce, and the exact error message.
- For an idea or improvement, open a Feature Request issue and describe the use case.
- Do not upload private `.pbox` packages, personal data, credentials, or proprietary
  application files to public issues.
- Remember that PocketBox is not a security sandbox; do not use it to run untrusted
  programs under the assumption that it isolates them.
